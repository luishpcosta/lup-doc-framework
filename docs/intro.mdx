# Introdução

Esta é a documentação do **framework híbrido**: um modelo de trabalho com IA integrada que vai do brief de negócio ao código gerado por IA em um único fluxo, com rastreabilidade em cada etapa.

> Esta página é um placeholder. O conteúdo técnico completo (duas análises, história, contenção de domínio no repositório e o harness Speckit SDD) ainda precisa ser escrito — ver `specs/` no repositório para o estado atual.

## O que você vai encontrar aqui

- **Visão executiva** — por que o modelo existe e qual problema resolve.
- **Blueprint técnico** — como as análises de negócio e técnica viram histórias rastreáveis, e como o harness Speckit SDD executa a implementação.

Veja também o [guia — preparar e usar um repositório de aplicação](./guia-agentes-ia-app.md).
