# Introdução

## Resumo executivo

O framework híbrido especializa o uso de ferramentas agênticas de IA por função dentro do ciclo de desenvolvimento: profissionais de produto usam agentes para conduzir a análise de negócio, líderes técnicos para a análise técnica, e desenvolvedores para especializar a implementação. Cada papel entrega ao próximo um resultado pronto para uso — não um ponto de partida solto. A aposta não é mais uma ferramenta de IA: é um caminho prático de como orquestrar as que já existem, por função, dentro de um único ciclo.

## O Problema

Existem dezenas de ferramentas agênticas disponíveis hoje — mas falta um caminho prático de como especializá-las por função dentro de um ciclo de desenvolvimento coerente. Cada pessoa adota a que prefere, para a tarefa que tem na frente, sem que o resultado de uma etapa se conecte à próxima.

## A Solução

O framework híbrido especializa o uso de IA por papel, dentro do mesmo ciclo:

- **Profissionais de produto** usam agentes para conduzir a análise de negócio.
- **Líderes técnicos** usam agentes para conduzir a análise técnica.
- **Desenvolvedores** usam agentes especializados na implementação.

Cada papel entrega ao próximo um resultado pronto para uso — a IA não é a mesma ferramenta genérica passando de mão em mão, ela é especializada para a etapa em que está.

## O que torna isto diferente

O caminho óbvio seria dar a mesma ferramenta genérica de IA para todo mundo e deixar cada pessoa descobrir sozinha como aplicá-la. O framework aposta no oposto: uma especialização agêntica por função — o profissional de produto usa IA para análise de negócio, o líder técnico para análise técnica, o desenvolvedor para implementação — e o resultado de uma etapa vira insumo direto da próxima, em vez de ser reconstruído do zero.

## Quem isto serve

- **Profissionais de produto** — conduzem a análise de negócio com apoio de agentes especializados.
- **Líderes técnicos** — conduzem a análise técnica com apoio de agentes especializados.
- **Desenvolvedores** — especializam a IA na implementação: do pipeline de execução a tarefas do dia a dia, como revisão de código assistida, testes gerados por agente e apoio a debugging.

## Critérios de sucesso

- Cada papel usa agentes especializados na própria etapa — não só IA genérica de produtividade pessoal.
- O que sai da análise de negócio chega à análise técnica sem reconstrução manual, e daí até o código.
- Um squad novo consegue adotar o modelo sem depender de treinamento informal.

## Escopo

**No escopo:** a especialização agêntica por papel (produto, técnica, desenvolvimento) e como ela se orquestra dentro do mesmo ciclo de desenvolvimento.

**Fora do escopo:** o detalhamento dos artefatos e do pipeline técnico que sustentam essa especialização — isso vive na página inicial e nos guias práticos, referenciados abaixo.

## Visão

O ponto de partida são três papéis — produto, técnica, desenvolvimento. A mesma lógica de especialização agêntica pode se estender a outros papéis do ciclo — QA, design, suporte — conforme o modelo se prova em produção.
